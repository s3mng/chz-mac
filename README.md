# Cracker

치지직 라이브 녹화 및 다시보기·클립 저장 앱입니다.

네이버 로그인 쿠키는 기기 로컬에만 저장되며, 외부로 전송되지 않습니다.

## 요구사항

macOS 14 이상, Apple Silicon에서 동작합니다.

## 설치

```sh
brew tap s3mng/chz-mac https://github.com/s3mng/chz-mac
brew install --cask cracker
```

## 주의사항

앱을 통해 저장한 영상의 저작권 및 치지직 이용약관 준수 책임은 사용자에게 있습니다.
